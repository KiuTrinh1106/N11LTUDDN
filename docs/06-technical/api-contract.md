## Quy ước chung

- Request có thể gửi `X-Correlation-Id`; Backend tạo mới nếu không có và trả lại
	correlation ID trong response header hoặc envelope theo implementation.
- `page` bắt đầu từ `1`; `pageSize` mặc định `20`, tối đa `100`. Timestamp dùng ISO 8601
	với timezone UTC.
- Error response thống nhất: `{ error: { code, message, details?, correlationId } }`.
	`message` không được tiết lộ tài nguyên ngoài quyền của caller.
- Command thay đổi trạng thái nên nhận `Idempotency-Key`, tối thiểu cho Publish và gửi
	Review, để retry không tạo bản ghi trùng.
- `version` là optimistic-concurrency token của tài nguyên; lỗi lệch version trả `409`.
- `ASK_AI` là permission riêng khi Q&A bị giới hạn theo tài liệu; mọi Q&A vẫn bắt buộc
	có `VIEW` trên nguồn được retrieval.
- `/api/ai/ask` above records the current backend response shape, not full conformance
  with REQ-FR-14 / REQ-NFR-04. Stable `versionId` citations and persisted per-answer
  source records are required by [the AI feature specification](../07-ai/ai-feature-spec.md)
  and must not be assumed implemented until verified.
