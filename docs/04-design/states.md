# State Matrix - AI Document & Knowledge Management System

## Mục đích

Bảng dưới đây quy định các trạng thái tối thiểu cần thiết cho Design System và các màn hình trong `screen-inventory.md`. Trạng thái phải được thể hiện nhất quán bằng text, màu, icon và hành vi; không dùng màu đơn lẻ để truyền đạt thông tin.

Các trạng thái nghiệp vụ của tài liệu gồm `Draft`, `Reviewing`, `Approved`, `Rejected` và `Published`. `VoiceControl` được đưa vào ma trận để bao phủ khả năng mở rộng voice/text; prototype hiện tại chỉ xác nhận luồng hỏi AI bằng văn bản, vì vậy voice cần được chốt phạm vi trước khi triển khai.

## Design tokens trạng thái

| Token                       | Gợi ý sử dụng                                                                                              |
| --------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `color.interactive.default` | Màu nền hoặc viền của control ở trạng thái mặc định; dùng nhất quán cho action chính.                      |
| `color.interactive.hover`   | Tăng tương phản nhẹ khi pointer đi qua; không làm thay đổi kích thước component.                           |
| `color.focus.ring`          | Focus ring có độ tương phản rõ, không bị cắt bởi container; áp dụng cho mọi control tương tác.             |
| `color.disabled`            | Màu chữ/nền giảm tương phản có chủ đích; component không nhận thao tác và không chỉ dựa vào opacity.       |
| `color.feedback.error`      | Validation error, request failure và retry state; luôn đi kèm thông điệp bằng text.                        |
| `color.feedback.success`    | Kết quả lưu, gửi Review, Approve hoặc Publish thành công; vẫn hiển thị text/icon.                          |
| `color.feedback.warning`    | Confirmation, hành động destructive hoặc cảnh báo version/quyền; cần mô tả hậu quả.                        |
| `spacing.control`           | Khoảng cách trong control phải ổn định giữa default, hover, focus, loading và error để tránh layout shift. |
| `shadow.overlay`            | Dùng cho Modal, Combobox và popover; không dùng shadow để thay thế focus hoặc phân cấp nội dung.           |

## State Matrix

| Component / Variant                             | State bắt buộc                      | Mô tả hành vi và điều kiện kích hoạt                                                                                   | Quy tắc hiển thị / Token gợi ý                                                                                                                      |
| ----------------------------------------------- | ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Button - primary, secondary, destructive, ghost | `default`                           | Sẵn sàng nhận thao tác; label mô tả đúng hành động như `Lưu`, `Gửi Review`, `Approve`, `Publish`.                      | `color.interactive.default`; chiều cao, padding và radius ổn định; destructive dùng `color.feedback.warning` khi cần xác nhận.                      |
| Button - mọi variant                            | `hover / focus`                     | `hover` xuất hiện khi pointer đi qua; `focus` xuất hiện khi keyboard hoặc assistive technology đưa focus vào.          | `color.interactive.hover`; `color.focus.ring` rõ ràng; không chỉ dùng thay đổi màu nền và không làm dịch layout.                                    |
| Button - mọi variant                            | `disabled`                          | Không thể thao tác khi thiếu quyền, dữ liệu chưa hợp lệ hoặc tiến trình khác đang chạy.                                | Giảm tương phản có kiểm soát bằng `color.disabled`; giữ accessible name; không dùng disabled để che mất lý do bị chặn nếu cần giải thích.           |
| Button - submit action                          | `loading`                           | Sau `Lưu`, `Gửi Review`, `Approve`, `Reject` hoặc `Publish`; khóa gửi lặp trong lúc request đang xử lý.                | Hiển thị spinner kèm text hoặc `aria-busy`; giữ nguyên kích thước bằng `spacing.control`; không đổi label làm layout nhảy.                          |
| Button - form/action                            | `error`                             | Request thất bại hoặc thao tác bị server từ chối; người dùng cần biết có thể thử lại hay sửa dữ liệu.                  | Liên kết với `color.feedback.error`; thông báo đặt gần action; giữ dữ liệu người dùng và cung cấp `Retry` khi phù hợp.                              |
| Input - text, password                          | `default / filled`                  | Chờ nhập hoặc đã có giá trị; dùng cho tên tài liệu, query và câu hỏi AI.                                               | Border và label ổn định; label không biến mất khi có giá trị; hỗ trợ `autocomplete` phù hợp.                                                        |
| Input - text, password                          | `hover / focus`                     | Người dùng di chuyển vào hoặc đang nhập liệu.                                                                          | Dùng `color.focus.ring`; không chỉ thay đổi placeholder; đảm bảo focus không bị che bởi overlay.                                                    |
| Input - text, password                          | `disabled`                          | Không cho nhập khi field phụ thuộc dữ liệu đang tải hoặc role không có quyền chỉnh sửa.                                | `color.disabled`; vẫn đọc được label và giá trị bởi assistive technology; không dùng disabled cho dữ liệu chỉ đọc nếu `readonly` phù hợp hơn.       |
| Input - text, password                          | `error`                             | Giá trị thiếu, sai format hoặc request trả về lỗi validation.                                                          | `color.feedback.error`; thông điệp gắn bằng `aria-describedby`; giữ giá trị đã nhập và đặt focus vào field lỗi khi phù hợp.                         |
| Search Bar                                      | `idle / typing`                     | `idle` khi chưa có query; `typing` khi Reader nhập từ khóa.                                                            | Hiển thị clear action khi có giá trị; hỗ trợ submit bằng `Enter`; debounce không được làm mất input.                                                |
| Search Bar                                      | `loading`                           | Sau khi Reader submit Search và hệ thống đang permission-aware retrieval.                                              | `aria-busy` ở vùng kết quả; khóa hoặc chống submit lặp; hiển thị trạng thái không làm mất query.                                                    |

## Quy tắc áp dụng cho screen-inventory

- Mỗi màn hình phải chỉ rõ state khởi tạo, state đang tải, state rỗng, state thành công và state lỗi nếu component đó có thể phát sinh các trạng thái này.
- Mọi thao tác bất đồng bộ như `Lưu`, `Gửi Review`, `Approve`, `Reject`, `Publish`, `Search` và `Ask AI` phải có `loading`, success/error và cơ chế retry phù hợp.
- Với permission-aware retrieval, trạng thái `Permission denied` không được tiết lộ title, metadata, citation hoặc sự tồn tại của tài liệu ngoài quyền.
- Voice input nếu được bổ sung phải luôn có text input thay thế; prototype hiện tại chỉ nghiệm thu text flow của `Search` và `Ask AI`.
