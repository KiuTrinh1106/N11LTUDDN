# MVP Scope & Out of Scope

| **Must**                                                                 | **Should**          | **Could**                | **Out of Scope**                         |
| :----------------------------------------------------------------------- | :------------------ | :----------------------- | :--------------------------------------- |
| Tạo tài liệu                                                             |                     | Gợi ý Tag                | Trợ lý AI bằng giọng nói                 |
| Chỉnh sửa tài liệu                                                       | Tìm kiếm nâng cao   | Gợi ý tài liệu liên quan | Tìm kiếm thông tin trên Internet         |
| Xem tài liệu                                                             |                     | Thống kê sử dụng         | AI tự động phê duyệt tài liệu            |
| Folder và Tag                                                            |                     |                          | Chỉnh sửa tài liệu đồng thời nhiều người |
| **Create → Review → Publish → Version**                                  |                     |                          | Tích hợp với hệ thống bên ngoài          |
| Quản lý quyền truy cập tài liệu                                          |                     |                          |                                          |
| Tìm kiếm tài liệu theo quyền được cấp                                    |                     |                          |                                          |
| Hỏi AI về nội dung tài liệu                                              |                     |                          |                                          |
| AI chỉ sử dụng tài liệu người dùng được phép truy cập                    |                     |                          |                                          |
| Lưu và xem lịch sử Version trong thời hạn retention                      |                     |                          |                                          |
| AI hiển thị và ghi lại tài liệu/version được sử dụng cho mọi câu trả lời |                     |                          |                                          |
| Lưu lịch sử hoạt động quan trọng                                         |                     |                          |                                          |
